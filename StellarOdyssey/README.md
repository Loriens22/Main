# Stellar Odyssey

A high-fidelity 3D space exploration game — **Kerbal Space Program's** orbital physics
meets **No Man's Sky's** seamless planetary exploration. Built for **Unity 2022.3 LTS + HDRP**.

## Architecture at a glance

**Precision.** Unity floats die a few km from origin. All authoritative state
(planet ephemerides, ship state vectors) lives in double-precision `Vector3d`
universe space. `FloatingOrigin` rebases the render world whenever the player
strays 6 km from origin; `ScaleSpaceManager` renders distant bodies on a
1:100,000 scaled layer so the whole true-scale solar system is visible.

**Orbits.** Planets are propagated analytically from Keplerian elements
("on rails") — stable at 100,000× time warp. The ship uses a hybrid: RK4
n-body integration while thrusting or in atmosphere, Kepler rails while
coasting (drift-free, exactly KSP's trick). Patched-conic sphere-of-influence
logic decides the dominant body.

**Planets.** Each body promoted into local space activates a quadtree
cube-sphere. Patches are generated by `PlanetTerrain.compute` on the GPU
(continents → ridged mountains → canyon carving → fine detail, plus biome
classification packed into vertex colors), read back asynchronously, and get
MeshColliders only near the surface. Depth 18–20 reaches sub-metre detail.

**Transitions.** `SeamlessTransitionManager` blends HDRP volume weights, sky,
fog, clouds, wind audio and aero forces continuously with altitude — no
loading screens. `AtmosphereEntry` converts real dynamic pressure and the
Sutton-Graves heating law into plasma VFX, hull glow, camera shake and damage.

## Quick start (Unity)

1. Unity Hub → New project → **3D (HDRP)** template, Unity 2022.3 LTS or newer.
2. Copy `Assets/` from this repo into the project.
3. Follow `Assets/Scenes/SceneSetup.md` to assemble the scene (≈15 minutes).
4. Press Play: you start in a 400 km Earth orbit. `Shift/Ctrl` throttle,
   `WASDQE` attitude, `G` gear, `V` camera, `M` map, `,`/`.` time warp.

## Playable web demo

`stellar-odyssey-demo.html` is a self-contained single-file WebGL demo
(no install, runs on mobile browsers) implementing the same core loop:
Newtonian gravity, orbital flight, procedural planets, wormhole travel,
atmospheric entry and landing. Open it in any browser.
