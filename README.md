## Interstellar: Beyond Endurance

Play in the browser: **https://loriens22.github.io/Main/interstellar/**

- Desktop: keyboard and mouse. Phone or tablet: touch controls, best held sideways (landscape).
  - Tapping **CREATIVE MODE** switches to full screen and locks landscape where the browser allows it (Android Chrome).
    iPhone Safari has no full-screen mode for web pages: use Share → **Add to Home Screen**, then start the game from
    that icon to play without the browser bars.
  - On foot: left stick to walk, drag on the right half to look, tap a door, switch or screen (or the **USE** prompt) to use
    it. Flying: left stick pitch and roll, right stick hover thrust and RCS, ◀ YAW ▶, the THR slider, **AUTO** for the flight
    computer. Photo mode: pinch to zoom.
  - Buttons appear only where they do something (the field tools on planet surfaces, the helmet lamp outside the cabin…).
    Settings → Controls lists every touch control and sets the look sensitivity.
- Settings → Graphics → "Run performance test" measures this device (or open the link with `?bench`).
- The site is published from this branch by `.github/workflows/pages-interstellar.yml` into `gh-pages/interstellar/`.
