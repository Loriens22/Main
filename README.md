## Cloudline — The Coastal Line

`index.html` is a complete, single-file 3D browser game built with Three.js.
Open the file in any modern browser and drive.

You are the driver of a retro green tram running the Coastal Line between two
islands floating above a sea of clouds — **Saltlight Terminus** and
**Mango Tide** — across elevated curves, long sea viaducts and a warm
dusk-to-night sky.

**Driving**

| Key | Action |
| --- | --- |
| `W` | Power |
| `S` | Brake |
| `A` / `D` | Trim — lean against a crosswind |
| `←` / `→` | Swing the camera |
| `C` | Change view (chase / cab / cinematic / wing) |
| `M` / `H` | Sound / driver's notes |

On a touch screen, hold the POWER and BRAKE pads and drag to look around.

**The idea.** Passengers judge the ride, not the clock. Sudden power, hard
braking, taking the elevated curves too fast and unanswered crosswinds all drain
*leg comfort*; stop on the mark at the platform and the tips follow. Smooth
stretches build a streak, and a rough one breaks it. Between runs you can visit
**Oliver's Cloudworks** to fit new parts — a turf roof, a luggage rack, a string
of lanterns, trailing ivy, an awning, coil springs — each of which changes how
the tram looks *and* how she rides.

Everything in the scene is generated in code: no textures, models or audio files
are loaded. Three.js is pulled from a CDN (with two fallbacks); nothing else is
required.
