# Happy birthday Matex

A ~3½-minute cinematic birthday film by the fictional studio **Neural systems L3WR5NCE**:
an Italian manor and a Bulgarian man fighting an old CRT, an antique natural-history garden
come to life, seven generations of Galaxy Fold assembling in a white studio, and two Huawei
tri-folds in deep space — ending with *“and everything you waaant”*, *“Happy birthday Matex”*
and a cake that falls and squashes a little.

Everything is generated by code in this repository: the 3D assets by **Blender 5.2** (Python
`bpy`), the film by a deterministic **Three.js / WebGL2** engine, the score, sound design and
voices by Python, and the final MP4 by a frame-exact headless renderer + FFmpeg.

## Quick start

```bash
npm install
npm run dev                       # http://127.0.0.1:5173  (realtime film + controls)
npm run build && npm run preview  # production build in dist/
```

Controls: play/pause (space), scrub, chapter buttons, mute, optional Bulgarian/English subtitles
(off by default), render-quality selector (auto adapts resolution to keep the frame rate), a
**Rendered 1080p** mode that plays the pre-rendered MP4, and **Download MP4**.

## Rebuilding every asset from source

| Step | Command | Output |
|---|---|---|
| Reference crops & procedural textures | `npm run assets:refs` | `public/assets/textures/**` |
| Blender models (bpy 5.2.3 LTS) | `npm run assets:blender` (needs `pip install bpy==5.2.3` in `/opt/bvenv`) | `public/assets/models/*.glb` |
| Score, SFX, dialogue, lip-sync | `npm run audio` (needs `fluidsynth`, MuseScore General sf3, `espeak-ng`, `numpy scipy soundfile pedalboard pyworld mido`) | `public/assets/audio/soundtrack.{wav,m4a}`, `stems/*.wav`, `lipsync.json` |
| Frame-exact 1080p24 video | `bash scripts/export/render_all.sh 1920 1080` (4K: `3840 2160`) | `frames/Happy_birthday_Matex_1080p.mp4` + web parts in `public/assets/film/` |

`render_all.sh` starts three headless-Chromium workers (Playwright) that open the built page in
export mode (`?export=1&w=1920&h=1080`) and call `window.__film.renderAt(t)` for every frame
`t = n / 24`. Workers interleave frames across the whole film (worker k renders n ≡ k mod 3) and
write each one atomically to `frames/seq/NNNNN.jpg`; existing frames are skipped, so the render
resumes after any interruption (`bash scripts/export/launch_detached.sh` restarts it), and a
single scene can be re-rendered by deleting its frame range. `encode.sh` then muxes the sequence
with the soundtrack (AAC 192 kb/s) into H.264 High/yuv420p with `+faststart`.
`split_parts.py` byte-splits the MP4 into ≤14 MB parts; the page re-joins them into one Blob that
is byte-identical to the file (SHA-256 in `manifest.json`).

Single stills for review: `node scripts/export/render_frames.mjs --times 3,23.5,92.5 --w 960 --h 540 --out shots`.

## Determinism

`render(t)` is a pure function of time. Every random choice (books, blossoms, butterflies, stars,
assembly paths, footprints) uses seeded `mulberry32`; physics-like motion (walk cycles, the
dinosaur gait, the cake fall and squash springs, petals) is analytic in `t`, so scrubbing, realtime
playback and frame export always agree. In realtime the audio element is the master clock.

## Phone rigs and hinge sheet

Panels are modelled in Blender at official dimensions (units: 1 = 100 mm) and placed by
`PhoneRig` along an analytic hinge **spine**: flat runs joined by circular arcs whose length is
π·r, so a 180° fold bends at exactly the hinge radius r. One continuous flexible display strip is
generated along the same spine every frame (dense in the arcs), with UVs across the full display,
rounded-corner/punch-hole masks and per-panel lighting.

from ref 02.

## Sound

All music is original and composed in `scripts/audio/build_audio.py` (notes placed in seconds,
locked to the timeline) and rendered per stem with FluidSynth + the MuseScore General soundfont:
a felt-piano/mallet/harp cue for the manor, an organ/strings/choir cue for the garden, a
generation-by-generation accelerating electronic cue (96 → 144 BPM) for the studio, and an
aspirational song for space with an original sung refrain (*“Beyond the night, new horizons
bloom / Through every shape, a wider sky appears / Open your wings, the stars are calling you /
Unfold the light, unfold the sky”*). The reference videos and *Stay* were treated as mood
references only; no melody, recording or lyric was copied. SFX (footsteps, button clicks, CRT
clunk/whine/snow, sofa, dinosaur footfalls, grunts, assembly clicks, hinge detents, novae, slide
whistle, splat, boing) are synthesised. Stems are written to `public/assets/audio/stems/`.

The Bulgarian lines are produced with espeak-ng's Bulgarian voice and re-performed through the
WORLD vocoder (time-fitted to the shot, new intonation contour, lowered formants, room acoustics);
the same pass exports the 60 Hz envelopes that drive the man's mouth. The refrain is sung by
espeak-ng English re-pitched to the melody with WORLD and doubled by choir.

## Known limitations (stated plainly)

- No GPU was available in the build container, so Blender Cycles could not render ~5,000
  frames; Blender generates the geometry, and the final video is rendered by the WebGL engine
  (SwiftShader) frame by frame. Lighting is PBR with shadow maps, bloom and a film grade, not a
  path tracer; DOF/SSAO were left out for render time.
- The characters are procedural (skin-modifier bodies, sculpted heads, morph-target mouths); they
  read as stylised animation characters rather than photoreal humans.
- The voices are synthetic (a neural Bulgarian voice model could not be used inside the sandbox).
  To use a real recording, drop it into `scripts/audio/vo.py` / `dialogue()` and rerun `npm run audio`
  — lip-sync is recomputed automatically.
- Phone geometry follows published dimensions and the reference photos; it is a careful
  reconstruction, not manufacturer CAD.

The phones appear as a birthday tribute; Neural systems L3WR5NCE is fictional and the film is not
affiliated with or endorsed by Samsung or Huawei.
