# STEVE THE PC REPAIR MAN — Build Contract v1

**Read this whole file before writing a line of code.** Every module is concatenated,
in order, into one `<script>` block inside a single self-contained HTML file. There is
no bundler, no modules, no `import`/`export`, no build step beyond concatenation.

---

## 0. Hard rules (violations break the build)

1. **Plain browser JS only.** No `import`, no `export`, no `require`, no `#!` , no JSX,
   no TypeScript annotations. ES2019 syntax max (no top-level await, no optional
   chaining `?.`, no nullish `??`, no class fields). Target: mobile Safari 14.
2. **No external assets, ever.** No URLs, no CDN, no `fetch()`, no `<img src="http...">`,
   no base64 blobs of copied art, no fonts beyond CSS generic families
   (`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` and `monospace`).
   Every pixel and every sample is generated by code at runtime.
3. **Wrap your whole file in an IIFE**: `(function(){ 'use strict'; ... })();`
   Attach exactly one thing to the global: your module object on `STV`.
4. **`THREE` is a global** (three.js r160 UMD). It is already loaded before your file.
5. **`STV` core is a global** and already loaded before your file (see §2).
6. **Do not touch `document.body` layout, `<style>`, or the canvas** unless you are
   the UI module.
7. **No `console.log` in shipped code.** Use `STV.log(...)` which no-ops unless debug.
8. **Deterministic**: seed all randomness through `STV.rng(seed)`. Never bare `Math.random()`
   for anything that affects world layout.
9. **Performance budget**: the whole scene must hold 60fps on a mid-range phone.
   Target < 500 draw calls per level, < 150k triangles. Reuse geometries and materials
   aggressively via the caches in §3. Never create a `THREE.Material` inside a loop.
10. **Dispose discipline**: anything you allocate per-level must be reachable from the
    returned level root `THREE.Group` so the engine can dispose it.

## 2. `STV` core API (already available to everyone)

```js

STV.randRange(rngFn,a,b)
STV.randInt(rngFn,a,b)  // inclusive
STV.pick(rngFn, array)

// Event bus
STV.bus.on(evt, fn)     // returns an unsubscribe function
STV.bus.once(evt, fn)
STV.bus.off(evt, fn)

// Registry helper for caches

```

### `STV.Geo` — mesh factories
Every factory returns a `THREE.Group` with:
- origin at **floor level, centred in XZ** (so `group.position.set(x, floorY, z)` just works),
- `group.userData.size = new THREE.Vector3(w,h,d)` — the bounding size,
- `group.userData.colliders = [ {type:'box', c:Vector3, h:Vector3} , ... ]` in **local**
  space (`c`=centre, `h`=half-extents). Physics reads this. Omit for non-solid props.
- Anything interactive gets `group.userData.interact = { label:'Examine', key:'e' }`
  — Levels will overwrite/extend this.

## 5. AGENT C — `src/40_ui.js` — `STV.UI`

Owns **all DOM outside the canvas**. Injects its own `<style>` at init.
Design language: precision-instrument. Thin lines, monospace accents, warm amber
(`#f0a24b`) + cold cyan (`#5fd3ff`) on near-black (`#0a0c0f`). Subtle grain.

### 5.1 Input — the single source of truth

```js
STV.UI.input = {
  move: {x:0, y:0},     // -1..1, y+ = forward.  Keyboard WASD or left stick.
  look: {x:0, y:0},     // delta this frame in radians-ish units; consumed by Player
  run: false,
  crouch: false,
  jump: false,          // edge-triggered, Player clears it
  use: false,           // edge-triggered, Player clears it
  alt: false,           // secondary action, edge-triggered
  pause: false,         // edge-triggered
  pointer: {x:0, y:0, down:false}   // normalised -1..1 for raycasting taps
};
```

**Mobile is a first-class citizen, not a fallback.**
- Left half of screen = floating virtual stick (appears where the thumb lands,
  with a dead-zone and a visible ring). Right half = drag-to-look with inertia.
- A **context action button** bottom-right that shows the current interact label
  and grows/glows when something is targetable. Crouch and run as thumb buttons.
- All controls must be reachable one-thumb on a 375×667 viewport, respecting
  `env(safe-area-inset-*)`.
- Must handle `touch-action:none`, prevent double-tap zoom, prevent rubber-band
  scroll, handle orientationchange, and offer a "rotate your device" nudge in
  portrait with a **Play in portrait anyway** option (never a hard block).
- Desktop: pointer lock on click, ESC to pause, standard WASD/Shift/Ctrl/Space/E.
- Provide an on-screen keyboard-free path for **every** interaction, including
  minigames and any place the game asks for typing.

### 5.2 Minigames (UI renders these as DOM overlays over the 3D view)

`STV.UI.minigame(id, opts, done)` — call `done(true|false)` on finish.
Required ids, each must be fully playable with touch *and* keyboard:

- `cmos` — Ms. Ellis's PC: pop the old CR2032 out and seat the new one.
  Drag-and-drop with a satisfying snap. Tutorialises interaction.
- `dossier` — read the target file: swipeable pages, redaction bars that wipe away.
- `security` — airport: route the toolkit's parts through the X-ray so nothing reads
  as a weapon. A small spatial packing puzzle on a 6×4 grid.
- `badge` — clone a keycard: match three waveform traces by dragging sliders until
  they align inside tolerance. Oscilloscope aesthetic.
- `wires` — the vault: cut/bridge a live harness. Colour-coded, with a continuity
  tester you must probe first. Wrong cut = alarm, not instant fail.
- `terminal` — a fake shell on Kestrel. Must be **playable without a keyboard**:
  offer tappable command chips as well as free typing. Commands:
  `help, ls, cat, ps, mount, dd, keys, purge, whoami, exit`. Scripted story beats.
- `solder` — steady-hand: hold the iron in the ring, follow a path, don't overheat.
- `lockpick` — service door: two-axis tension/pick, haptic-ish feedback via UI.
- `panic` — escape sequence: a rhythmic 4-button QTE that ramps.

Each minigame gets a short in-fiction framing line at the top and a **Skip** affordance
after two failures (accessibility — never hard-block progress).

### 5.3 Accessibility
Subtitles always on by default, size-adjustable. A settings panel (gear, top-right)
with: master/sfx/music/voice sliders, voice on/off, subtitle size, invert-Y,
look sensitivity, motion-reduction, "high contrast targets", and a quality toggle.
Persist to `localStorage` under key `stv.settings`.

## 6. AGENT D — `src/50_levels.js` — `STV.Levels`

```js
STV.Levels.list          // ordered array of level ids
STV.Levels.build(id, ctx)  // -> LevelObject   (ctx = {scene, camera, renderer, physics, rng})
```

`LevelObject`:
```js
{
  id, root,                 // THREE.Group added to scene
  spawn: {pos:Vector3, yaw:Number},
  bounds,                   // THREE.Box3 for the playable area
  lights: [],               // added under root
  colliders: [],            // {type:'box', c:Vector3(world), h:Vector3} — static
  interactables: [],        // see below
  actors: [],               // NPCs/AI, each with update(dt)
  env: { fog, sky, ambient, exposure, footstep:'carpet'|'tile'|..., ambience:'shopRoom' },
  update(dt, player),       // per-frame
  onEnter(player),          // called once after level:ready
  dispose()
}
```

Interactable:
```js
{
  obj,                       // THREE.Object3D (raycast target; put a simple proxy mesh if needed)
  label:'Replace CMOS battery',
  key:'e',
  radius:2.2,                // max distance
  enabled:true,
  once:false,
  onUse(player, level),      // do the thing
  onFocus(bool)              // optional: highlight
}
```

## 7. AGENT E — `src/60_cutscenes.js` — `STV.Script`, `STV.Cine`

### `STV.Cine` — the cinematic engine
```js
STV.Cine.play(id, ctx)     // -> promise-like; ctx = {scene,camera,level,player}
STV.Cine.skip()
STV.Cine.playing            // bool
STV.Cine.register(id, def)
```
A cutscene definition is a **timeline of beats**:
```js
{
  id:'c_oleg',
  music:'olegTheme',
  letterbox:true,
  shots:[
    { t:0, dur:4.2,
      cam:{ from:{pos:[x,y,z], look:[x,y,z], fov:38}, to:{...}, ease:'inOutSine' },
      dof:{focus:2.4, blur:0.6},           // fake DOF via a post overlay is fine
      line:{ who:'oleg', text:'...', voice:'oleg' },
      do:function(ctx){ /* pose actors, open briefcase, etc */ },
      sfx:'briefcaseOpen'
    },
    ...
  ],
  onEnd:function(ctx){}
}
```
Requirements:
- Real camera language: dolly, push-in, rack focus (fake DOF is fine), handheld
  micro-shake, whip pans, a **cut** (instant shot change) as well as moves.
- Letterbox bars in/out, film grain, subtle chromatic aberration during tension,
  a slow desaturation on the twist.
- Actors must actually be posed and animated (`setPose`, `update(dt,{talking:true})`)
  so mouths move on the speaking character.
- Every line goes through `STV.bus.emit('dialogue:line', ...)` so UI subtitles and
  `STV.Voice` both fire. Shot duration must be `max(dur, voiceEstimate)`.
- **Skippable at any time** (tap/ESC), with a confirm-free single press, and skipping
  must leave the world in the correct post-scene state (run all `do` handlers).

### The script — write it well
This is the soul of the thing. Steve is dry, economical, and kind. He never
brags. He calls Oleg "Mr. Thomas" in front of clients. Ms. Ellis talks about her
late husband Harold and her grandson who "does something with computers too".
Oleg is warm in a way that is somehow worse than cold. He never says the word "kill".

**Beats to hit (required):**
- `c_intro` — title over black; the shop; Ms. Ellis and the Windows 98 tower;
